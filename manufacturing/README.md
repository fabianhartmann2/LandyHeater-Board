# Fertigungsdaten

Dieses Verzeichnis ist für freigegebene, eindeutig versionierte PCB- und PCBA-Pakete vorgesehen. Arbeitsausgaben werden reproduzierbar unter `build/` erzeugt und nicht eingecheckt.

Fertigungsdaten werden erst in Phase 5 nach abgeschlossenem Schaltplan-, Layout- und Manufacturing-Review freigegeben.

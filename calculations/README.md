# Berechnungen

Dieses Verzeichnis nimmt die nachvollziehbaren Auslegungsnachweise auf, insbesondere Strombudget, Ruhestrombudget, Verlustleistung, Versorgungsschutz, Reglerbeschaltung, Leiterbahnbreiten, thermische Abschätzung und RTC-Backup-Laufzeit.

Berechnungen beginnen in Phase 1. Annahmen, Formelquellen, Bauteiltoleranzen und Worst-Case-Ergebnisse müssen dokumentiert werden.

Vorhanden:

- [Leistungs-, USB- und Ruhestrombudget Revision A](Leistungs-und-Ruhestrombudget_Revision_A.md)

Die detaillierte TVS-/Eingangsschutz-, Buck-, eFuse-, Frontlicht- und Diagnosezweigberechnung folgt mit den finalen Passivwerten in Phase 2.
